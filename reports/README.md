Значения таблиц округлены до шести знаков. Полные значения и данные каждого класса находятся в JSON.

В `sample.jar` классы `Point` и `P1`–`P4` наследуют `X`, поэтому максимальная глубина равна 1, а средняя — `5 / 8`. Шесть классов реализуют метод интерфейса `Y`, поэтому среднее количество переопределений — `6 / 8`. Семь классов содержат по одному полю, а `AKt` не содержит полей: среднее — `7 / 8`.

`fescar.jar` и `guava.jar` — архивы с деревьями проектов: в анализ входят также находящиеся внутри `.class` из `target/test-classes`. Вложенные библиотеки `.jar` не раскрываются. Из 6637 `.class`-записей Guava пропущены 17 `package-info.class`; оставшиеся 6620 типов состоят из 6375 классов и 245 интерфейсов.
